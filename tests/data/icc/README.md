# ICC profiles for the `@color-profile` tests

Small synthetic profiles, copied from the `color` library's test data (they are generated from CIE arithmetic, not from a vendor's profile).

| profile | what it is |
|---|---|
| `srgb_g22.icc` | sRGB primaries, gamma 2.2 |
| `displayp3_g22.icc` | Display P3, gamma 2.2 |
| `gray_g22.icc` | grayscale, gamma 2.2 |
| `swap_rg.icc` | sRGB with red and green exchanged, linear |
| `rgb_mab.icc` | an RGB table profile (lutAtoBType) |
| `cmyk_mft2.icc` | a CMYK table profile |
